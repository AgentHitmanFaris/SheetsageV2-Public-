# NC- AtoScore

Professional AI-powered music transcription software for Windows.

## Features

- Audio-to-MIDI transcription
- Multiple AI models (Basic Pitch, Piano, Drums)
- Video file support
- Native Windows UI
- GPU acceleration

## Quick Start

1. Clone this repository
2. Run `setup_local.bat`
3. Run `run_local.bat`

## Requirements

- Windows 10/11
- NVIDIA GPU (recommended)
- 8GB RAM minimum
